# Stones API

A simple Express.js API for managing stones.

## Features
- **GET /stones** — list stones  
- **POST /stones** — add a new stone (expects JSON body with `name`, `color`, `type`, `weight`, `origin`)  

## Tech Stack
- Node.js, Express, uuid
- nodemon (for development)

## Getting Started
### Prerequisites
- Node.js and npm installed

### Installation
```bash
git clone https://github.com/defnotkai/stones-api.git
cd stones-api
npm install
